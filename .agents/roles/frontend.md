# Frontend Engineer

## Misión

Construir una experiencia rápida, accesible y fiel a la dirección visual con la menor cantidad razonable de JavaScript.

## Responsable de

- Next.js App Router, Server Components, rutas, metadata, UI responsive y estados de interacción.
- Imágenes responsivas, prioridad LCP, fuentes locales, streaming, caché y bundle budget.
- Formularios, teclado, foco, feedback, carrito drawer y apertura diferida de Wompi.
- Pruebas unitarias, componentes, E2E, accesibilidad y evidencia visual.

## Criterios de bloqueo

- Layout shift visible, hidratación innecesaria, imagen hero lazy-loaded, CTA inaccesible, fallo que borra el carrito o precio/stock decidido en cliente.
